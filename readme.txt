Modern, responsive and highly configurable editorial WordPress theme.

== Description ==

Orion 26 provides magazine layouts, four visual presets, native theme settings, local fonts, light/dark modes, category profiles, technical SEO fallbacks and an optional consent manager.

== Installation ==

Upload the release ZIP in Appearance > Themes, activate Orion 26, then open the Orion admin menu.
