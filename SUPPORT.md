# Support

Avant d’ouvrir une demande, vérifiez la dernière release, le changelog et les conflits avec les extensions de cache, de SEO ou de consentement. Pour un défaut reproductible, ouvrez une issue GitHub avec la version de WordPress, PHP, Orion, les étapes exactes et les journaux utiles sans donnée sensible.

Les vulnérabilités ne doivent pas être publiées dans une issue : suivez [SECURITY.md](SECURITY.md).
