# Sécurité

Signalez une vulnérabilité en privé via la fonction de signalement de sécurité GitHub du dépôt. N’ouvrez pas d’issue publique avant correction.

Les versions maintenues sont la dernière version majeure et son dernier correctif. Le gestionnaire de consentement est un mécanisme technique de chargement conditionnel ; sa configuration et sa conformité juridique restent sous la responsabilité de l’éditeur du site.
