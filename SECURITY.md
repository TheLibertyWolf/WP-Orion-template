# Sécurité

Signalez une vulnérabilité en privé via la fonction de signalement de sécurité GitHub du dépôt. N’ouvrez pas d’issue publique avant correction.

Les versions maintenues sont la dernière version majeure et son dernier correctif. Le gestionnaire de consentement est un mécanisme technique de chargement conditionnel ; sa configuration et sa conformité juridique restent sous la responsabilité de l’éditeur du site.

Le sous-menu de délégation exige `manage_options`, même lorsqu’un utilisateur dispose de `manage_orion26_settings`. Les champs de scripts exigent `unfiltered_html`. Les signalements doivent préciser la version concernée et éviter toute donnée personnelle, clé ou code de suivi réel.

L’installateur de plugins utilise une liste fermée de dépôts HTTPS, des nonces et les capacités natives WordPress. Il respecte `DISALLOW_FILE_MODS` et ne tente jamais de contourner une politique serveur interdisant les installations.
