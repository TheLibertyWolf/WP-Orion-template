# Contribuer

Créez une branche ciblée, conservez la compatibilité PHP 8.1, échappez toute sortie et validez les droits/nonces de chaque écriture. Les changements visuels doivent être vérifiés en clair, sombre, mobile et clavier. Les nouvelles chaînes doivent utiliser le domaine `orion26` et être reportées dans le POT.

Avant une pull request, exécutez la syntaxe PHP, compilez les catalogues Gettext et construisez le ZIP. N’ajoutez jamais de clé, cookie, export de base de données ou configuration d’un site réel.
